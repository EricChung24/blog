# C# Day 2–4 教學插圖設計

## 目標

為 C# Day 2、Day 3、Day 4 各加入一張主視覺，讓讀者在閱讀程式碼前先掌握該篇文章的核心流程。

## 視覺方向

- 統一使用深色程式教學插畫風格，搭配藍綠色、紫色與暖黃色重點色。
- 圖中不放任何可讀文字或程式碼，避免 AI 產生錯字。
- 圖片採寬幅橫式構圖，適合作為 Markdown 文章標題下的主圖。
- 圖片內容只解釋概念，不替代文章內的完整程式碼與說明。

## 三張圖片

| 文章 | 視覺主題 | 要傳達的概念 |
| --- | --- | --- |
| Day 2 | 有編號格子的資料列，透過迴圈箭頭逐格處理 | 陣列、索引、迴圈 |
| Day 3 | 輸入進入方法方塊，經運算後輸出；背景為規律乘法格線 | 參數、回傳值、巢狀迴圈 |
| Day 4 | 猜測輸入通過驗證節點，再分流到重試或成功結果 | `TryParse`、條件判斷、`while` 迴圈 |

## 實作方式

1. 以內建影像生成工具分別產生三張 PNG。
2. 將最終圖片存入各篇文章自己的目錄，避免共用資產造成命名混亂。
3. 在每篇文章的開頭說明後插入圖片，並加入描述性的替代文字。
4. 執行 Hugo 建置驗證，確認圖片路徑與文章渲染正常。
5. 只提交插圖與三篇文章的 Markdown 變更，再推送觸發 GitHub Pages 部署。

## 驗收條件

- 三篇文章各有一張可顯示的主圖。
- 三張圖片視覺風格一致，且不含錯誤或不可讀的內嵌文字。
- Hugo 能成功建置。
- GitHub Pages 部署流程成功完成。
